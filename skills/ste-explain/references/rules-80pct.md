# 80% STE rules (own paraphrase, not ASD text)

1. One idea per sentence. Split commas and stacked clauses.
2. Short sentences. Default advisory limits are UNVERIFIED (20 procedural / 25 descriptive).
3. One name per thing. Pick canonical term, replace all synonyms.
4. Procedural = imperative. Start with verb: Remove, Install, Check.
5. Descriptive = active. Name the actor. Passive only if actor truly unknown.
6. Condition first. If reader must know it before the step, lead with If/When.
7. Avoid -ing. Use base verb or noun. Keep only technical nouns like opening (noun).
8. No filler. Delete prior to, in order to, it is imperative that.
9. Keep every fact. Numbers, conditions, hedges (may, can, might) survive.
10. Flag uncertainty. If unsure of approved word, keep term and list in Waivers.
