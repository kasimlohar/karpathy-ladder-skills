# Advisory substitutions (small subset, NOT a dictionary)

Use only as hints. If meaning changes, keep original term and waive.
Official dictionary is ASD property — request via https://www.asd-ste100.org/

- begin, commence, initiate -> start (advisory)
- utilize, utilise -> use
- prior to -> before
- ensure that all components have been inspected -> examine all components
- carry out, accomplish -> do
- approximately (adverb of amount) -> flag: STE `about` means `concerned with`, do NOT auto-replace; keep number + tolerance or waive
- -ing forms -> base verb unless technical noun (opening as noun is allowed)

Do not invent approved status. When in doubt, flag.
